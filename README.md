An enhanced, modern take on the classic Snake game — rebuilt with smooth controls, dynamic difficulty, and polished visuals. This project extends the traditional mechanics with power-ups, obstacles, new game modes, and clean code architecture designed for easy expansion.

🚀 Features
Core Gameplay

Classic Snake movement with smooth, responsive controls

Growing tail mechanics

Collision detection (self, wall, obstacles)

Advanced Enhancements

Multiple difficulty levels with increasing snake speed

Procedural food spawning with anti-spawn logic to avoid unreachable spots

Obstacles that appear as you progress

Power-ups such as:

Slow-time

Wall-pass

Bonus food

Dynamic camera or board scaling (if implemented)

Polish & UX

Clean UI with animated transitions

Score tracking + high-score saving

Pause menu and restart options

Sound effects and optional background music

Customizable settings (controls, colors, speed, grid size)
